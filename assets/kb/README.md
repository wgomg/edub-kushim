# Offline lexical knowledge base artifacts

This directory holds the converted lexical sources the knowledge base installs into Postgres. Each
`*.tar.gz` is generated by `scripts/gen_kb_artifacts.py` and consumed by `internal/kb`; the files are
tracked through Git LFS (`.gitattributes`), so the repository stores pointers and the downloader resolves
the objects through the LFS Batch API.

Every artifact contains `manifest.json` plus `concepts.tsv`, `lemmas.tsv` and `edges.tsv`. The manifest is
the machine-readable provenance record: upstream URL and hash, license, notice, conversion filters, row
counts, and the converter version whose mapping produced the rows. The installer validates it and refuses an
artifact without a license or notice.

## Regenerating

```sh
python3 scripts/gen_kb_artifacts.py --all
```

The script writes the artifacts under `build/kb/` after verifying the pinned upstream hashes. To publish a
new generation, copy the artifacts here and commit them together with the matching `(version, sha256)` pins
in `internal/kb`; a download that does not match the pin fails loudly and installs nothing. The filenames are
stable per upstream edition, so the pointer URLs never change across regenerations.
